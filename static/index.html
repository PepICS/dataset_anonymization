Fase 01

Carrega el fitxer CSV

El fitxer ha de tenir exactament 4 columnes: pacient, data, item, valor.

⚠️ Una sessió = un dataset. Si tens dades de línies assistencials independents (atenció primària, hospitalària, sociosanitària…), has d'executar una sessió per a cadascuna i mantenir-les separades. El mode multi-fitxer és només per a un mateix dataset trossejat per dominis temàtics (mateixos pacients, variables sense solapar).
